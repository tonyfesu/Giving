<product_requirements>
ImpactLink aims to be a platform connecting businesses and individuals with social causes, enabling transparent impact. The core problem is integrating social impact with commerce and identifying purpose-driven entities.

The application has been iteratively enhanced with the following features and functionalities:
*   **Impact Allocation Engine & Tracking**: Core functionality for transparent impact.
*   **User & Business Features**: API for direct contributions, admin pages, leaderboards, and a badge system.
*   **Payment Methods**: Support for multiple methods (cards, Mobile Money, PAPSS, bank transfers) and anonymous contributions.
*   **Cause Management**: Enhanced with start/end dates, expiry, filtering, and creator attribution.
*   **Subscription Module**: Tiered plans for users and businesses.
*   **Leaderboards**: Reporting functionality per cause.
*   **Demo Data**: Provision of diverse demo user accounts (admin, business, individual) and 10 sample data entries for 5 causes.
*   **Settlement System**: Account/phone number-based payouts for causes, integrated into the Create Cause flow.
*   **Developer Platform**: Comprehensive platform with API documentation and SDKs.
*   **UI/UX Refinements**: Refined hero section text, removal of Admin tab from global navigation and Settlement tab from business user navigation.
*   **Social Features**: Shareable links, emoji reactions, comments on causes, and admin response to comments.
*   **Business Dashboard Enhancements**: Display contributions per cause, allow responses to comments, and provide cause health overview.
</product_requirements>
