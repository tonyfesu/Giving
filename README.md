# Nnoboa - Social Impact Platform

Nnoboa is a comprehensive platform that enables businesses to drive social change through commerce by connecting sales to social causes with transparent impact tracking.

## Features

- **Impact Allocation Engine**: Transparent impact tracking and allocation
- **Business & Individual Support**: Connect purpose-driven entities with social causes
- **Direct Contributions**: GoFundMe-style donation system
- **Leaderboards & Badges**: Gamification for social impact
- **Admin Dashboard**: Comprehensive platform management
- **Developer Platform**: API integration for third-party developers
- **Social Features**: Share causes, comment, and react with emojis
- **Settlement System**: Transparent payout management

## Technology Stack

- **Backend**: FastAPI (Python)
- **Frontend**: React.js
- **Database**: MongoDB
- **Styling**: Tailwind CSS
